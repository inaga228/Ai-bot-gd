# AI Level Bot for Geode (Geometry Dash 2.2)

Прототип мода для **Geode**, который имитирует простого "ИИ-бота":

- играет за игрока в запущенном уровне;
- после смерти запоминает позицию смерти;
- на следующих попытках пытается нажать прыжок около выученных позиций;
- если включен `auto-restart`, автоматически перезапускает попытку.

> ⚠️ Это **MVP-прототип**, а не полноценный RL-бот. Но это хорошая база для дальнейшего развития.

## Что уже реализовано

- Hook в `PlayLayer` (`init`, `update`, `destroyPlayer`).
- Простая память `deathPoints` по X-координате.
- Повторное применение выученных действий (jump) в окне `decision-window`.
- Настройки Geode (`enabled`, `auto-restart`, `decision-window`).

## Идеи для улучшения

1. Учитывать не только X, но и скорость, режим (cube/ship/wave), гравитацию.
2. Хранить несколько типов действий (tap/hold/release).
3. Фильтрация шумных точек и кластеры смертей.
4. Сохранение памяти по `levelID` между сессиями (JSON).
5. Визуализация выученных точек прямо в уровне.

## Сборка

1. Установи Geode SDK/toolchain.
2. В корне проекта:

```bash
cmake -B build
cmake --build build
```

3. Установи собранный мод через Geode.

## Важно

Мод рассчитан на **Geometry Dash 2.2** (в `mod.json` указана ветка 2.2074 для Win/Android).
