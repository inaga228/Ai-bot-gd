# AI Level Bot for Geode (Geometry Dash 2.2)

Это улучшенный MVP-прототип мода для **Geode**, который имитирует простого бота:

- отслеживает позицию игрока в текущем уровне;
- после смерти запоминает опасные позиции;
- на новых попытках использует выученные точки как основу для будущей логики действий;
- может автоматически перезапускать попытку.

## Что реализовано сейчас

- Hook в `PlayLayer` (`init`, `update`, `resetLevel`, `destroyPlayer`).
- Память по точкам смерти с **кластеризацией** (близкие смерти объединяются).
- Ограничение памяти (`max-memory`), чтобы список не рос бесконечно.
- Базовая логика обучения по смертям без рискованных платформо-зависимых инпут-вызовов.
- Настройки Geode:
  - `enabled`
  - `auto-restart`
  - `decision-window`
  - `merge-window`
  - `max-memory`

## Дальше можно добавить

1. Сохранение памяти между сессиями (по `levelID`).
2. Разные действия (hold/release длительность, mini-тайминги).
3. Учет режима игрока (cube/ship/ball/wave) и скорости.
4. Визуализацию точек обучения в рантайме.

## Сборка

```bash
# Linux (автоустановка Geode CLI + SDK + сборка)
./scripts/setup-geode-linux.sh

# или ручная сборка (если Geode уже установлен)
cmake -B build
cmake --build build
```

Если SDK не находится автоматически, задай переменную окружения:

```bash
export GEODE_SDK=/path/to/geode/sdk
cmake -B build
cmake --build build
```

## Важно

Это не полноценный RL/нейросетевой агент, а эвристический обучающийся бот-скрипт.
